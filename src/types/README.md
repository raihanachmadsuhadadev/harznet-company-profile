# Type Bersama

Folder ini hanya menampung type atau interface yang digunakan lintas feature. Type khusus feature tetap berada di feature terkait.

Hindari duplikasi type yang dapat diinfer oleh TypeScript. Gunakan type yang eksplisit pada batas data eksternal, tetapi jangan membuat generic type yang belum memiliki kebutuhan nyata.

Tidak ada file type aktual yang ditambahkan pada tiket ini.
